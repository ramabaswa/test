Meet Iggy, a made-up agent from Enterprise Quality Engineering (EQE) that writes test cases. Before Iggy can do any work, it needs an identity and permission to use tools. Follow Iggy from the first request to its first tool call. Hover over any dotted term for a plain-words definition.
